3. Content sniffing in UploadsService (replace the "known limitation" with the check; keep the comment honest about what is and isn't checked): for a declared type that has a known signature, the buffer must match it or the upload is refused with the existing 400 style:
     application/pdf → starts with `%PDF-`
     DOCX → starts with `PK\x03\x04` AND the ZIP contains an entry named `word/document.xml` (scan the ZIP central directory / local headers for that filename bytes; no new dependency — a bounded byte search of the buffer for the entry name within a valid ZIP is acceptable; explain your approach)
     image/png → `\x89PNG\r\n\x1a\n`; image/jpeg → `\xFF\xD8\xFF`; image/webp → `RIFF....WEBP`
